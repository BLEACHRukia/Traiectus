显示器输入源 + 鼠标控制权跟着键盘一起换边。Fn 组合键是键盘固件的事，Traiectus 负责"看见"它走了，然后让其它设备跟上。

鼠标跨机

鼠标插在 Windows 上，事件经局域网转发到 Mac 注入。Windows 本地鼠标照常可用 —— 打游戏不受影响。

提前 1.7 秒切屏

Windows 侧只读监听键盘接收器的状态帧，比 Mac 自己发现键盘离开更快把画面切过去。没有这个接口的键盘也照常能用，只是少这点提前量。

睡眠一键交接

在 Mac 上按一个组合键（默认 ⌘1）睡眠，同时把屏幕和鼠标交给 Windows；唤醒后自动切回。

怎么工作

两端各跑一个小程序，只用一条局域网 TCP 连接（默认 45789）。没有云端、没有账号、没有遥测。

  • 只读：Windows 侧只捕获 Raw Input，不拦截、不注入、不改系统设置、不装驱动。
  • 断开即失效：Mouse 模式默认 "Windows 原生"，连不上就什么都不做。
  • 退出即干净：从托盘退出，服务端、看门狗、光标锁定一起清掉。

先看前提

不符合这几条的话，它帮不上你 —— 提前说清楚，比装完才发现好。

  • 键盘要能自己换主机内置 Fn 组合键在"蓝牙主机"和"2.4G / 有线主机"之间切换的键盘。Traiectus 不能命令键盘换主机 —— 它只是看见键盘走了。
  • 显示器支持 DDC/CI绝大多数现代显示器都支持，且两台机器接在不同输入口（例如 Mac → HDMI-1，Windows → DP-1）。
  • 两台机器在同一局域网有线、Wi-Fi 都行，能互相访问即可。
  • 提前切屏需要键盘有厂商状态帧接口实测的 Corsair K70 Pro Mini 有。没有这个接口的键盘一切照常，只是"去 Windows"方向慢约 1.7 秒。

常见问题

它和硬件 KVM 的区别？

不用多一根线、不用多一个盒子、不用按盒子上的按钮。代价是需要一台常开的电脑做服务端（这里是 Windows），并依赖局域网。

会被游戏反作弊影响吗？

Windows 侧只读捕获输入，不注入、不改内存、不 hook。作者自己的做法是：玩竞技游戏前直接退出 Traiectus，环境最干净。

Mac 版为什么打不开？

因为它没有 Apple 开发者签名（那要 99 美元/年）。第一次「右键 → 打开」即可；若提示「已损坏」，在终端执行 xattr -dr com.apple.quarantine /Applications/Traiectus.app 再打开。

支持我的键盘吗？

只要它能自己换主机就能用。带厂商状态帧接口的（例如 Corsair K70 Pro Mini）有「提前切屏」，别的键盘少这 1.7 秒提前量，功能一样用。

安全吗？会不会把我的输入发到网上？

不。只有一台电脑到另一台电脑的局域网连接，没有云端、没有账号、没有遥测。鼠标只在「控制权在 Mac」时转发。
