## 三、执行方案（四阶段）

### Phase 0 · 决策（需要用户拍板）

1. **许可证**：建议 MIT（与 vendored 的 m1ddc 一致）；在意专利用 Apache-2.0；要求传染开源用 GPL-3.0。
2. **历史策略**：建议**新建干净公开仓库 + 单次初始提交**，私有仓库保留开发历史。
3. **名字与范围**：`MiniKVM` 与已有硬件项目重名，建议改用 UI 里已在用的 **Senkaimon**；
   v0.1 **如实声明硬件要求**（Corsair K70 Pro Mini + 2.4G 接收器 + 支持 DDC/CI 的显示器），通用化放 v0.2 —— 
   "一次 Fn 切换全部"依赖该键盘固件，换键盘即失效，必须写在 README 最显眼处。

### Phase 1 · 脱敏

- 口令 → 改成参数/配置文件，仓库只放 `config.example`，真配置 gitignore（顺带修掉"硬编码口令"这个设计问题）
- 序列号 → 占位符
- `~` → `~/`；`%USERPROFILE%` → `%USERPROFILE%`
- 内网 IP → 文档用占位符；脚本改为参数（默认值保留 192.168.1.x 私有网段无妨）

### Phase 2 · 仓库清理

- 删 `macos/phase3-tcp.bak-20260926/`
- 二进制不入库（`kvm-keywatch` 有源码 + `build.sh`）；`m1ddc` 注明上游来源与版本
- 删 `tools/publish-to-openlist.py`（个人工具）、`工作流约定.md`（AI 协作约定）不公开
- `reports/` + `联调记录.md` **脱敏后保留** → 移到 `docs/devlog/`（逆向过程本身是加分项）

### Phase 3 · 对外文档

`README.md`（英）+ `README.zh-CN.md`、`docs/ARCHITECTURE.md`、`docs/PROTOCOL.md`、
`docs/TROUBLESHOOTING.md`（收录已知坑：鼠标必须无线、显示器 DDC/CI 开关、辅助功能权限、
防火墙 UDP 45791/45790、多实例互相污染日志）、`LICENSE`、`THIRD_PARTY_NOTICES.md`。

### Phase 4 · 构建与发布

Windows：`build-mingw.bat` / CMake；macOS：`build.sh` + `make-signing-identity.sh`（用户自签证书说明）；
可选 GitHub Actions 双端编译。
