# 固定地址连接（0.1.1）

多网卡或网线直连时，自动发现可能在编辑地址、断线重连时把手动地址覆盖为另一张网卡的地址。

在「设置 → 连接 → 连接设置」选择「固定地址」，填写 Windows 地址并点「保存并连接」。固定模式只重试已保存的地址，忽略 UDP 心跳来源和自动扫描结果。没有选择模式的旧安装继续使用自动发现，启动时自动连接是独立开关。

地址先写入草稿，保存时校验完整 IP 或主机名；输入期间不会触发重连，也不会接受自动发现覆盖。切换模式、开始编辑、手动断开都会作废在途扫描。手动断开后，心跳不再重新启动连接。

验证：

- 地址策略测试 30/30：固定模式、编辑状态、停止连接、旧扫描晚到、地址校验。
- 生产客户端回环集成测试 9/9：握手、断线期间旧 IP 心跳、禁止扫描、服务恢复自动连回、手动断开和无效草稿。
- arm64 / macOS 14+ 完整编译通过，使用现有 Traiectus 证书签名。

测试命令：`./tools/peer-address-test/run.sh`、`python3 tools/peer-address-test/run-integration.py`。集成测试只监听回环端口 45788，不发送鼠标键盘事件，使用独立测试偏好域。
