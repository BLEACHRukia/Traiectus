## 0. 你要做的事情，一句话

在 Mac 上把这个小程序编译出来、授权「辅助功能」、然后点按钮验证"Mac 能用官方 API 合成鼠标动作"。

---

## 1. 确认文件已经在 Mac 上

位置：仓库里的 **`macos/phase2-cgevent/`**

把这 4 样下载/复制到 Mac 同一个文件夹里（文件夹名保持 `phase2-cgevent`）：

```
phase2-cgevent/
├─ build.sh                  ← 编译脚本
├─ Info.plist                ← App 元信息
└─ src/
   └─ MiniKVMPhase2.swift    ← 全部源码
```

> 只放到"下载"文件夹里也能编译，不用非得放进 /Applications。

---

## 2. 编译（3 条命令）

打开 Mac 的「终端」，先把路径切到那个文件夹，例如：

```bash
cd ~/Downloads/phase2-cgevent        # 换成你实际放的位置
```

然后依次三条：

```bash
chmod +x build.sh
./build.sh
```

**成功的样子：**

```
✅ 构建完成： build/MiniKVM.app
```

**如果报错** —— 最常见的是两种：

| 报错 | 原因 / 解决 |
|---|---|
| `command not found: swiftc` | 没装编译工具。终端执行：`xcode-select --install`，装完再跑一次 |
| `bad interpreter: /bin/bash^M` | 文件被 Windows 加了 CRLF 换行。解决：`sed -i '' 's/\r$//' build.sh` 再跑 |

其他报错：把完整错误发我。

---

## 3. 运行 + 授权

```bash
open "build/MiniKVM.app"
```

窗口出现后：

1. 看最上面一行：红点 = 未授权
2. 点 **「请求权限」**（或点 **「打开系统设置」** 直接跳过去）
3. 路径：**系统设置 → 隐私与安全性 → 辅助功能**
4. 列表里如果没有 `MiniKVM` → 点左下角 **+**，添加：

   ```
   <你放的位置>/phase2-cgevent/build/MiniKVM.app
   ```

5. 打开右边开关
6. **⚠️ 退出这个 App 再重新打开**（权限只在启动时读取，不重启不生效）

重开之后，最上面那行应该变成**绿点 = 已授权**。

> 授权之后**不要再移动这个 .app 的位置**，否则权限绑定会失效，要重新授权。

## 4. 测试（5 项）

按顺序点按钮，对照"预期表现"：

| # | 点哪个按钮 | 预期表现 |
|---|---|---|
| 1 | **移动测试（画圈）** | 光标以当前位置为圆心画一个圆，约 1 秒画完，**然后回到原位** |
| 2 | **左键**（先把光标移到桌面空白处）| 产生一次真实左键单击 |
| 3 | **右键** | 弹出右键菜单 |
| 4 | **中键**（建议在浏览器里，光标放在链接上）| 新标签页打开链接 |
| 5 | **滚轮上 / 滚轮下**（光标放在能滚动的窗口上）| 内容向上/向下滚动 3 格 |

最后点 **「▶︎ 全套测试（约 6 秒）」**，它会依次做完上面全部动作，日志里逐条记录。

## 6. 这个阶段为什么这样做（背景）

- 用的是 Apple **现行**官方 API：`CGEvent`（合成鼠标）+ `AXIsProcessTrusted`（权限检查）
- 只申请「辅助功能」权限，**不申请**完全磁盘访问
- 不用 Qt、不装任何第三方库、不需要 Homebrew
- 只在你这台 Mac 上生效，**对 Windows 侧零影响**
- Phase 3 会把 Windows 抓到的鼠标事件通过 TCP 发过来，Mac 端就是用这套代码落地执行
