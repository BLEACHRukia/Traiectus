Traiectus

A crossing, from one shore to the other.
From Win to Mac. One monitor, one keyboard, one mouse.
Press once, and everything follows.
Download Read the docs

What it is

A piece of software you install on both computers.
No switcher to buy, no extra cables to run.
Both computers share one keyboard, one mouse and one screen.

Both stay up and running, exactly as before.
Just one LAN connection between them.
The keyboard, mouse and screen follow you to the other side.

It doesn't touch your system

Read-only input capture, no drivers. Quit and it’s back as it was.

How to use

  1. Set it up · WindowsUnzip it and double-click Traiectus.exe — a green dot appears in the tray
  2. Set it up · MacDrag Traiectus.app to Applications, then right-click → Open
  3. Grant access · Mac
    • Accessibility — required, or forwarded clicks do nothing
    • Local Network — asked on the first connection to Windows; click Allow
    Auto-start can be turned off under General → Login Items
    Input Monitoring / Screen Recording / Full Disk Access aren't needed
    Only if you use the sleep hotkey does it ask for one extra permission, Automation (click Allow when it asks)
  4. Let it through on Windows
    • On first launch Windows shows a firewall prompt — tick “Private networks” → Allow
    • No administrator rights, no drivers, no registry changes
  5. Click AllowThe first time the Mac connects, a dialog pops up on Windows — click Allow
  6. Teach it your monitorDisplay page → Start learning → switch the monitor input when it asks
  7. Teach it your keyboardKeyboard page → Start learning → press your keyboard’s switch key each time it asks
  8. Start using itPress the switch key, and the keyboard, mouse and screen all follow you over
