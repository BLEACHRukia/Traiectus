按一下，全都跟着走。
下载 使用文档

它是什么

一套装在电脑上的软件。
不用买切换器，也不用多接线。
两台电脑共用同一套键盘、鼠标和屏幕。

两台电脑都照常开着。
只通过一条局域网连接。
键盘、鼠标和屏幕跟着你换到另一边。

它不会动你的系统

只读捕获，不装驱动，退出即还原。

如何使用

  1. 装上去 · Windows解压后双击 Traiectus.exe，托盘出现绿点就成了
  2. 装上去 · Mac把 Traiectus.app 拖进「应用程序」，右键打开
  3. 给它权限 · Mac
    • 辅助功能 —— 必开，否则鼠标点了没反应
    • 本地网络 —— 第一次连 Windows 时弹框，选「允许」
    开机自启可以在「通用 → 登录项」里关掉
    不需要输入监控、屏幕录制、完全磁盘访问
    只有用「睡眠热键」时才会多要一个「自动化」权限（弹框时选「允许」）
  4. 给 Windows 放行
    • 第一次启动时 Windows 会弹防火墙提示 —— 勾「专用网络」→「允许」
    • 不用管理员权限，不装驱动，不改注册表
  5. 点一下允许Mac 第一次连过来时，Windows 上会弹确认框，点「允许」
  6. 教它认显示器「显示」页 → 开始学习 → 按提示用显示器按钮切一次
  7. 教它认键盘「键盘」页 → 开始学习键盘切换 → 按提示用键盘上的切换键各切一次
  8. 开始用按一下键盘上的切换键，键盘、鼠标、屏幕一起跟过去
