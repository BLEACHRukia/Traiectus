Traiectus

一把键盘，两台电脑。
按一次键，键盘、鼠标、显示器一起跟着走。

不用买硬件 KVM。Mac 和 Windows 都原生运行，Traiectus 只是把输入设备和显示器的输入源在它们之间搬来搬去。

下载 (GitHub Releases) 源码

Windows / macOS 两个 zip，未签名 —— 首次打开要「右键 → 打开」（Windows 上是 SmartScreen「仍要运行」）。

它能做什么

  • 一次按键全切按键盘上「切到 Windows / 切回 Mac」的快捷键，显示器的输入源和鼠标控制权一起跟着切。
  • 鼠标跨机鼠标插在 Windows 上，事件经局域网转发到 Mac 注入。Windows 本地鼠标照常可用。
  • 提前切屏Windows 侧只读监听键盘接收器的状态帧，比 Mac 自己发现键盘离开早约 1.7 秒切屏。
  • 睡眠一键交接在 Mac 上按一个组合键（默认 ⌘1）睡眠，同时把屏幕和鼠标交给 Windows；唤醒后自动切回。
  • 不用查任何 ID鼠标是哪只由服务端自动识别；键盘在设置里点一下就能选；显示器输入源编号是「学」出来的。
  • 不装驱动、不 hookWindows 侧只读捕获 Raw Input：不拦截、不改系统设置、不装驱动、不用内核扩展。

先看前提 —— 不符合的话它帮不上你

  • 键盘要能自己换主机：内置 Fn 组合键在「蓝牙主机」和「2.4G / 有线主机」之间切换的键盘。Traiectus 不能命令键盘换主机 —— 它只是「看见」键盘走了，然后让屏幕和鼠标跟着走。
  • 显示器支持 DDC/CI，且两台机器接在不同输入口上。
  • 两台机器在同一个局域网里。
  • 提前切屏需要键盘有厂商状态帧接口（实测的 Corsair K70 Pro Mini 有）。没有这个接口的键盘一切照常，只是「去 Windows」方向慢约 1.7 秒。

三步用起来

  1. Windows：解压 zip → 双击 Traiectus.exe → 托盘出现绿点。（第一次弹防火墙询问选「允许」）
  2. macOS：把 Traiectus.app 拖进「应用程序」→ 右键 → 打开 → 在「辅助功能」里给它打勾。
  3. 配对：第一次 Mac 连过来时 Windows 上会弹一个确认框，点「允许」。没有口令要填，地址也会自己找到。

常见问题

它和硬件 KVM 的区别？

不用多一根线、不用多一个盒子、不用按盒子上的按钮。代价是：需要一台常开的电脑做服务端（这里是 Windows），并且依赖局域网。

会被游戏反作弊盯上吗？

Windows 侧只读捕获输入（Raw Input），不注入、不改内存、不 hook。不过玩竞技游戏时，作者自己的做法是直接退出 Traiectus —— 环境最干净。

Mac 版为什么打不开？

因为它没有 Apple 开发者签名（那要 99 美元/年）。第一次「右键 → 打开」即可；如果提示「已损坏」，在终端执行 xattr -dr com.apple.quarantine /Applications/Traiectus.app 再打开。

支持我的键盘吗？

只要它能自己换主机就能用。带厂商状态帧接口的（比如 Corsair K70 Pro Mini）有「提前切屏」，别的键盘少这 1.7 秒的提前量，功能一样用。
